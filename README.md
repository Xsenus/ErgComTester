# ErgComTester (Auto Mode by default)

**Запуск без параметров делает всё автоматически:** собирает максимум диагностик, сканирует все COM‑порты, пытается найти устройство, выгружает данные пациентов (если нашёл), опционально синхронизирует время, пишет подробный лог и формирует ZIP‑пакет поддержки (`ERG_Support_*.zip`).

## Сборка
```bash
dotnet build -c Release
```

## Запуск (по умолчанию — AUTO)
```bash
dotnet run -c Release --
```
После завершения ищите:
- Логи: `./logs/ergtester_YYYYMMDD_HHMMSS.log`
- «Сырые» блоки: `./out/raw/*.bin`
- Итоговый пакет: `./ERG_Support_YYYYMMDD_HHMMSS.zip`

### Ручные режимы (при необходимости)
- `--list` — только вывести список COM‑портов.
- `--single --port=COM5` — проверка конкретного порта.

### Опции
- `--nofetch` — не выгружать пациентов (только детект).
- `--rtctime` — отправить установку времени после операций.
- `--nozip` — не собирать итоговый ZIP.
- `--baud=115200`, `--retries=3`, `--quiet=120`, `--readwin=1500` — параметры таймингов.
- `--nodtr`, `--norts`, `--notoggle` — управление линиями.
- `--min-ci=136`, `--min-pb=64` — минимальные размеры для завершения чтения пакетов.
