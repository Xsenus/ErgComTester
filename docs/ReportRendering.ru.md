# Генерация отчетов (DOCX и PDF)

## DOCX (Word)

* Базовая генерация выполняется через Open XML SDK (`DocumentFormat.OpenXml`).
* Шаблон создается программно (`ErgReportBuilder.BuildPatientWordReport*`).
* Для новых систем Windows 8+ используется единый код без ограничений.
* Для старых систем (Windows 7) совместимость обеспечивает дополнительная инфраструктура:
  * Принудительно создаются базовые стили, таблицы и шрифтовая таблица (Calibri/Arial).
  * Вставляются части `settings.xml`, `core.xml`, `app.xml` и корректируется `[Content_Types].xml`.
  * Включается режим совместимости Word 2010 и автозаполнение полей при открытии.
* На устаревших системах ничего не переключается вручную — `RenderingSupport` определяет ОС и на уровне сервисов предупреждает о режиме совместимости.

## PDF

* На современных системах применяется QuestPDF + SkiaSharp (`BuildPatientReportQuestPdf*` / `TryRenderGraphImageWithSkia`).
* На Windows 7 и при отсутствии SkiaSharp срабатывает запасной путь `LegacyPdfRenderer` (GDI+) и GDI-графики (`TryRenderGraphImageWithGdi`).
* Проверка ОС/окружения и переключение режимов выполняется в `RenderingSupport`: если `UseLegacyPdfGeneration/UseLegacyGraphRendering` истинны, то сервисы используют старый код и выводят предупреждение в лог.
* Независимо от режима сохраняются одинаковые данные: однотипные таблицы измерений, шапка из настроек и одинаковые маркеры/оси графиков.
