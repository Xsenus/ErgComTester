# Настройка масштабов и маркеров ЭРГ-графиков

Этот документ описывает итоговое состояние логики подготовки данных для отчётов после фикса ошибок масштаба.

## Преобразование дискретов в микровольты

* Сырые значения графиков (Int16) переводятся в микровольты делением на `GraphDiscrPerMkV`.
* Для каждого индекса `i` рассчитывается пара `(t_i, uV_i)`, где `t_i = i * GraphDt`, а `uV_i = raw[i] / GraphDiscrPerMkV`.
* Дополнительные масштабные коэффициенты не применяются.

## Границы осей

* Шкалы X и Y берутся из метаданных записи: `GraphXScaleMin/Max`, `GraphXValueStep`, `GraphXLineStep` и аналогичные параметры для оси Y.
* Графики обрезаются по диапазону X, если данных больше, чем позволяет окно отображения.

## Маркеры волн

* Маркеры `a` и `b` формируются только если соответствующее значение в миллисекундах попадает в диапазон `[GraphXScaleMin, GraphXScaleMax]`.
* В отчётах QuestPDF/SkiaSharp и GDI выводятся вертикальные пунктирные направляющие и подписи только для валидных маркеров.
* Если маркер выходит за пределы оси (пример: 255 мс при X 0–100 мс), линия не рисуется, а в таблицах выводится `—` для амплитуды.

## Проверки целостности

* При сборке отчёта проверяется, что каждая серия содержит `GraphNumPoints` точек.
* Для плоских серий (`IsFlat = true`) график строится в обычном режиме, но дополнительно настраивается узкий диапазон оси Y.

Эти правила применяются как в PDF, так и в DOCX отчётах, обеспечивая совпадение данных с JSON-файлами пациентов.
